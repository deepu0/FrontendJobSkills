# Frontend Cover Letter

Most remote frontend roles do not read these. Write one only if the form requires it or they asked.

## When to Use

- JD or ATS has a cover-letter field
- User asks for a letter for a **frontend** role

Skip if they already have a referral and the company said "no letter".

## Shape (150–220 words)

1. One line: role + company + the matching stack.
2. One proof: a metric they actually have (LCP, users, design-system adoption, a11y).
3. One sentence on why **this** product (from the JD, not "your mission inspires me").
4. Close: timezone overlap if remote, link to portfolio + GitHub.

No "I am writing to express my interest". No restating the whole resume.

## Truth

If they do not have the required framework, do not claim a 2-week ramp as production experience. Name the adjacent stack and stop.

## Output

```markdown
# Cover letter — [Role], [Company]

[body]

## Why this version
- Stack words taken from: …
- Metric taken from: …
```
