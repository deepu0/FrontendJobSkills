# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge
Be kind, inclusive, and respectful. Frontend is for everyone — junior to staff, React to Svelte.

## Standards
- Use welcoming language
- Respect different views and experience levels
- Give constructive feedback
- Focus on what is best for the community

## Not acceptable
- Harassment, discrimination, or personal attacks
- Trolling or insulting comments
- Publishing private info without consent

## Enforcement
Report issues to the maintainers via GitHub Issues (or email the repo owner via GitHub profile). All reports are reviewed promptly and confidentially.

## Attribution
Based on Contributor Covenant. Enforcement guided by GitHub community standards.
